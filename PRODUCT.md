# Predictive Maintenance Control Center
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Streamlit, Python 3.11, pandas, scikit-learn, Plotly. Specified in the assignment brief.

## Users
A university student demonstrating a Cloud Computing assignment to an evaluator.

## Product Purpose
Explore official synthetic AI4I observations, classify operating conditions, and inspect
reproducible ML evaluation. Success is working local inference and a verifiable cloud demonstration.

## Operating Context
Windows development, local training, browser dashboard, later guided Google Cloud deployment.

## Capabilities and Constraints
Six predictors, binary Machine failure target. No future horizon, live feed, or industrial
safety claim. Four pages and CSV inference. Cloud integration is optional locally.
Only measured results may be displayed. Preserve the $300 cloud trial credits.
The dashboard displays calibrated failure-probability estimates, with a default High precision
policy and a validation-selected Balanced F1 alternative. Changing policy changes only classification.
The original uncalibrated winner stays preserved. Cloud deployment is the final step under
the user's direct supervision; no cloud configuration or resource operations are authorized here.

## Brand Commitments
Professional technical dashboard, dark navy and charcoal, restrained teal or blue,
clear typography, well-spaced analytical content, responsive layout. User-supplied brief.

## Evidence on Hand
Official data/raw/ai4i2020.csv; separate professor reference checkout with MIT license.
No measured results exist until training is executed.

## Product Principles
Scientific honesty; reproducible experiments; clear input validation; local independence;
manual cloud deployment after local verification.
